# Security Policy

This repository documents a private defensive security lab.

## Rules

- Do not publish real credentials.
- Do not publish public IPs tied to your home or workplace.
- Do not publish private keys, tokens, API keys, or Splunk admin passwords.
- Do not run testing steps against third-party systems.
- Sanitise screenshots before committing.

## Recommended Sanitisation

Before pushing to GitHub, remove:

- Passwords
- Email addresses
- Real names unless needed
- External IP addresses
- Tokens/API keys
- Full machine GUIDs/SIDs if not required
